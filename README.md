# 📱 嗖嗖移动 Web 营业厅系统 (Sousou Mobile Service Hall)

这是一个基于 **前后端分离架构 (Spring Boot + Vue 3)** 实现的虚拟通信运营商在线自助营业厅系统。

本项目的核心特色在于**完全不依赖外部关系型数据库 (RDBMS)**，自研了一套基于 **Java 集合框架 + 原子性文件 I/O 序列化** 的轻量级文档型 NoSQL 存储引擎。同时，前端创新性地构建了一个 **3D 高仿真智能手机（嗖嗖 Phone）** 运行沙盒，实现了多态计费、无损 FLAC 音频 5G 流媒体实时计费滚动歌词等前沿交互。

## ⚙️ 环境准备与基础配置

在运行项目前，请确保您的本地开发环境已安装并配置以下工具：

### 1. 后端依赖
*   **Java Development Kit (JDK)**: JDK 1.8 或 JDK 17
*   **Apache Maven**: 3.6.x 及以上
*   **音频资源就位**：请将至少一首包含内嵌封面和歌词的无损 `.flac` 格式音乐放入后端的 `sousou-backend/src/main/resources/static/music/` 文件夹下。

### 2. 前端依赖
*   **Node.js**: v16.x 或 v18.x (推荐)
*   **Package Manager**: npm 8.x 或 yarn
*   **手机壁纸就位**：请将一张你喜欢的手机壁纸（推荐尺寸 `1080x1920`）重命名为 `wallpaper.jpg`，放入前端的 `sousou-frontend/public/` 目录下。

##  部署与运行指南

### 第一步：启动后端服务 (Spring Boot)

1. 打开终端，导航至后端根目录：
   ```bash
   cd sousou-backend
   ```
2. 清理并编译项目：
   ```bash
   mvn clean install
   ```
3. 运行 Spring Boot 服务：
   ```bash
   mvn spring-boot:run
   ```
4. **验证**：后端默认运行在 `8080` 端口。在浏览器打开 `http://localhost:8080/api/music/list`，若能正常输出解析后的 FLAC 歌词与 Base64 封面 JSON，说明后端启动成功。

---

### 第二步：启动前端服务 (Vue 3 / Vite)

1. 新开一个终端窗口，导航至前端根目录：
   ```bash
   cd sousou-frontend
   ```
2. 安装依赖包：
   ```bash
   npm install
   ```
3. 启动 Vite 本地开发服务器：
   ```bash
   npm run dev
   ```
4. **运行**：控制台会输出本地访问链接，通常为 `http://localhost:5173/`。在浏览器中打开即可开始体验。

## 📖 核心业务演示与教学指南 

在进行答辩、演示或自测时，建议按照以下**最优业务闭环路径**进行操作展示：

### 步骤 1：资费说明与开户（展示排重与多态初始化）
1.  在营业厅主页左侧点击“资费说明”，系统会发起 `GET /api/user/tariffs` 接口请求展示三大套餐价格。
2.  点击“开户注册”：设置密码并选择“网虫套餐(NET)”，点击确认。
3.  **讲解词**：*“此时后端注册服务启动，自动生成以 139 开头的手机号。为了确保数据安全，后端会深入 JSON 物理数据库执行排重检索，保证分发的号码绝对不冲突，并在注册成功后自动扣除网虫套餐的首月月租 68 元。”*

### 步骤 2：登录与进入手机沙盒
1.  复制注册成功的手机号，在登录页输入密码完成登录。
2.  进入工作台，右侧是详单，左侧是一台极具品质感的智能手机。手机状态栏显示“嗖嗖5G”及实时电量、时钟。
3.  点击桌面的 **“掌上营业厅” App**：这里集成了话费充值、流量订购、套餐变更等原生服务，手机已完全实现自主业务闭环。

### 步骤 3：体验 5G 无损流媒体与实时扣费（核心看点）
1.  按下 Home 键返回桌面，打开 **“音乐” App**。
2.  页面通过高防 iOS 的 Backdrop-filter 渲染出基于当前歌曲封面的高斯模糊晕染背景。双击或点击右上角“歌词”，可以切换为“歌单”或“同步滚动歌词”面板。
3.  点击播放按钮。黑胶唱机唱针落下并开始旋转。
4.  **展示计费**：由于当前是 5G 传输无损 FLAC 音乐，你可以观察到右侧的消费详单表格：**每隔 3 秒就会准时弹出一行“上网：7MB”的扣费记录**。
5.  按下 Home 键退回桌面：状态栏药丸屏会自动收缩并激活**绿色动态岛**，显示 `🎵 5G 播放中...`，代表后台计费守护线程依然安全运转。

### 步骤 4：账户停机保全阻断展示（容错展示）
1.  音乐持续播放，账户余额不断减少。
2.  当余额扣减至负数瞬间，由于余额已不足以支持下一次 3 秒 7MB（0.7元）的额外话费，**手机会瞬间强行将音乐暂停**，动态岛收回，并弹出“余额已耗尽，嗖嗖 5G 网络流媒体传输已中断”的警告框。
3.  **讲解词**：*“系统在计费层设计了严格的防透支保护。一旦守护线程检测到扣费失败，会立即向前端派发阻断指令，强行关停音乐播放，避免了传统文件数据库在高并发下的负债穿透。”*

### 步骤 5：掌上营业厅充值与详单分页展示
1.  打开手机内的“掌上营业厅”，选择充值 `50元`，充值成功，余额和顶部告警消退。
2.  返回“音乐” App，可以继续畅听。
3.  进入系统右侧的“消费详单”面板。此时流水众多，你可以向评委展示**每页 15 行的干净分页**。
4.  鼠标悬浮到右上角的刷新按钮上，你可以看到**刷新图标旋转 180 度，并以平滑拉伸动画浮现出“刷新详单”四个汉字**，体验极为丝滑。

### 步骤 6：在线套餐变更与办理退网（生命周期完结）
1.  在“掌上营业厅”点击变更套餐为“话唠套餐(TALK)”，变更成功，扣除月租。
2.  回到“音乐”播放。由于话唠套餐没有免费流量，计费引擎会自动判定用户未实现 `INetService` 接口，自动采取全额扣减计费。
3.  演示结束。在主控板或营业厅内申请“办理退网”。
4.  **讲解词**：*“退网后，系统会结算余额并完成销户。我打开本地的 `sousou_users.json` 文件，可以发现该手机号的所有数据已经完全在物理层面被安全擦除。”*
